## 1. Problem

Canvas re-renders when ANY dashboard mutates (incl. filter changes in OTHER dashboards). `dashboards` only used for `hasDashboards = dashboards.length > 0` (l:46). `isDirty` only used at l:48.
- **B2 (MED)** `dashboard-list.tsx:13-20` — whole-object `useDashboardsStore()` no selector → re-renders on every store change (widget add/remove/layout/filter in any dashboard).
- **B3 (MED)** `dashboard-selector-dialog.tsx:19` — whole-object `useDashboardsStore()` → re-renders on every store change even when dialog closed.

## 3. Implementation (direct edit, no specialist — <40 lines mechanical 3 files)

### P1 `dashboard-canvas.tsx`

Replaced 12-field `useShallow` (lines 22-39) with 3 narrower selectors:

```ts
const activeDashboard = useDashboardsStore(
  useShallow((s) => s.dashboards.find((d) => d.id === s.activeDashboardId) ?? null)
)
const activeDashboardId = activeDashboard?.id ?? null
const hasDashboards = useDashboardsStore((s) => s.dashboards.length > 0)

const { updateLayout, saveDashboard, publishDashboard, unpublishDashboard, updateWidget, addFilter, removeFilter, clearFilters, createDashboard } =
  useDashboardsStore(useShallow((s) => ({ /* 9 actions */ })))

const isDirty = activeDashboard
  ? activeDashboard.updatedAt > (activeDashboard.lastSavedAt ?? 0)
  : false
```

Dropped: `dashboards` array subscription, `isDirty` function subscription, `activeDashboardId` subscription (derived from `activeDashboard`).

**Why `activeDashboard` via `useShallow` find is correct**: `updateOneAndTouch` (l:98-108) returns non-matching dashboards by reference (`.map()` preserves refs for unchanged elements). So `.find()` returns same ref when only OTHER dashboards mutate → `useShallow` equality passes → no re-render. When target dashboard mutates → new ref → re-render (correct).
