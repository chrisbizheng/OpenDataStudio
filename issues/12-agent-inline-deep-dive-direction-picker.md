## Parent

#9 Agent 图表节点详情增强 + AI 深度分析方向选择 PRD

## What to build

Change the `AI 深度分析` interaction in the Agent chart node detail card from immediate execution to inline direction selection.

When the user clicks `AI 深度分析`, the node detail card should expand a list of up to four recommended analysis directions. The list should initially be generated by the local deep dive direction recommender. Each option should be displayed as a compact button in the same visual style as existing Agent follow-up suggestions.

The picker should also offer an `AI 推荐方向` action. When clicked, the app calls the configured LLM through a lightweight backend endpoint to generate more contextual direction labels and prompts. If LLM generation fails or the LLM is not configured, the local directions remain available.

When the user chooses a direction, Agent Chat sends that direction's prompt as the next user message. The direction picker should then close or the clicked-node state should clear so stale direction options do not remain visible.

## Acceptance criteria

- [ ] Clicking `AI 深度分析` no longer immediately sends the old fixed prompt.
- [ ] Clicking `AI 深度分析` expands inline direction options inside the node detail card.
- [ ] The picker shows no more than 4 options.
- [ ] Direction buttons use the existing Agent follow-up suggestion visual style.
- [ ] The picker includes an `AI 推荐方向` action that can replace local options with LLM-generated options.
- [ ] LLM direction generation failure keeps local options usable and does not break the picker.
- [ ] Clicking a direction sends that direction's prompt through the normal Agent Chat send flow.
- [ ] After a direction is selected, the picker closes or the clicked-node state is cleared.
- [ ] Direction labels respect the current UI language.
- [ ] If the recommender returns no options, the UI does not crash and does not show an empty broken picker.
- [ ] Existing chart detail viewing still works when the user does not open the deep dive picker.
